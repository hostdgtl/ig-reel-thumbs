# ig-reel-thumbs

First-frame thumbnails for archived Instagram reels, one folder per profile.

Served over `raw.githubusercontent.com` so Google Sheets `=IMAGE()` can render them —
Sheets refuses to render Google Drive-hosted images, which is why these live here.

Generated by `tools/ig-reels.js` (see `skills/ig-reels.md` in the stores-os repo).
